# Roybabu Mangayomi Extensions

Experimental manga sources for Mangayomi.

## Add this repository

In Mangayomi, open Settings > Browse and add the following as a manga extension repository:

```
https://raw.githubusercontent.com/Roybabu/Mangayomi-extension-/main/index.json
```

Refresh the extension list and install **Read Comics Online**.

## Status

The source was written using the website layout observed in November 2026. It has not yet been tested in Mangayomi 0.9.97 or on Android. Test browsing, searching, chapters and images; the website may require security verification via the source WebView.
